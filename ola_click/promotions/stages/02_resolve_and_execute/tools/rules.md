# Promotions — Tool rules

Use `manage_promotions` and the operation from the module extraction rules. For a native creation request, `coupon_code` is the redeemable code and an existing promotion is identified by its UUID as `id`.

## Native promotion tools

| Tool | Scope / kind | Required arguments | Optional arguments | When and how to use |
|---|---|---|---|---|
| `get_active_promotions` | `promotions:read` / read | — | `service_type` (string (`delivery`, `takeaway`, `onsite`, `table`)), `applies_to` (string (`all_products`, `selected_products`)), `redeemable_now` (boolean), `timezone` (string) | List published promotions with redemptions left. For current eligibility also set redeemable_now and Europe/Lisbon to apply the weekly schedule. |
| `list_promotions` | `promotions:read` / read | — | — | Browse the valid and published promotions that have redemptions left. Use get_active_promotions for time-of-day eligibility. |
| `get_promotion` | `promotions:read` / read | `id` (UUID) | — | Inspect one promotion by its UUID. Resolve a coupon code to the matching record first. |
| [`create_promotion`](https://developers.olaclick.app/docs/mcp#create_promotion) | `promotions:write` / write | `name` (string), `coupon_code` (string), `discount_type` (string (`percentage`, `amount`)), `discount_value` (number > 0), `minimum_order_amount` (number ≥ 0), `valid_from` (string), `valid_until` (string), `usage_limit` (integer > 0 or null), `published` (boolean) | `promotion_type` (string (`default`, `products`)), `products` (array of object) with {`id` (string) required, `name` (string) required}, `service_types` (array of string), `audience` (string (`all_customers`, `only_new_customers`)), `usage_limit_per_customer` (string (`unlimited`, `only_once_per_customer`)), `schedule` (object) with {`active_days` (array of string) required, `time_from` (string or null) required, `time_to` (string or null) required}, `terms` (string) | Create a coupon with a validity window, discount, minimum order amount, usage limit and published flag. Confirm scope of eligible products, services and customers. |
| [`update_promotion`](https://developers.olaclick.app/docs/mcp#update_promotion) | `promotions:write` / write | `id` (UUID) | `name` (string), `coupon_code` (string), `discount_type` (string (`percentage`, `amount`)), `discount_value` (number > 0), `minimum_order_amount` (number ≥ 0), `valid_from` (string), `valid_until` (string), `usage_limit` (integer > 0), `published` (boolean), `promotion_type` (string (`default`, `products`)), `products` (array of object) with {`id` (string) required, `name` (string) required}, `service_types` (array of string), `audience` (string (`all_customers`, `only_new_customers`)), `usage_limit_per_customer` (string (`unlimited`, `only_once_per_customer`)), `schedule` (object) with {`active_days` (array of string) required, `time_from` (string) required, `time_to` (string) required}, `terms` (string) | Send only requested fields. The API can set fields but cannot clear them with null. |
| [`delete_promotion`](https://developers.olaclick.app/docs/mcp#delete_promotion) | `promotions:write` / destructive | `id` (UUID) | — | Delete the promotion by verified UUID. This permanently removes it. |

- **Promotions.** For a percentage coupon use `discount_type: "percentage"` and `discount_value: 20` for 20%. Omit `schedule` for no weekly restriction. To specify one, send `active_days` as uppercase weekday names and `time_from`/`time_to` as `HH:mm`. For a product restriction, pair `promotion_type: "products"` with verified `{id,name}` entries.
- `create_promotion` and `update_promotion` use lowercase `percentage` and `amount` upstream. Order discounts use uppercase `PERCENTAGE` or `AMOUNT`.
